FILOVA Backup

Encrypted backups in your own Google Drive, for a single owner's personal use.

What it does

FILOVA Backup is a desktop application that its owner runs on their own computer. It uses the open-source tools restic and rclone to keep backups of the owner's files in a folder of the owner's Google Drive.

  • Backup contents are encrypted on the computer before they are uploaded, and the backup password is never uploaded to Google Drive. The backup folder also holds the repository files restic needs: key files that contain the repository key encrypted with the backup password, and some technical details that are not encrypted, such as file sizes and dates (see the Privacy Policy).
  • The application creates one backup folder in Google Drive and uses only that folder.
  • It reads the Drive storage total and usage, so the owner is warned before the space runs out.

Google permission

FILOVA Backup asks for one permission: https://www.googleapis.com/auth/drive.file. With it, an application can reach only the Google Drive files it created, or files the user explicitly opened or shared with it, for example through a Google file picker. It cannot see the rest of Google Drive.

FILOVA Backup has no file picker and never asks for files to be shared with it: it uses only the backup folder it created and the files in that folder.

Who can use it

This is not a public service. There is no sign-up, no server and no other users: the application runs only on its owner's computer, with the owner's Google account.
