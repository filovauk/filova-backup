Privacy Policy

FILOVA Backup · Effective 29 October 2026

FILOVA Backup is a desktop application that its owner runs on their own computer, for personal use, to keep encrypted backups in their own Google Drive. It is not offered to other users. This policy explains how it accesses, uses, stores and shares Google user data.

Data the application accesses

  • With the https://www.googleapis.com/auth/drive.file permission, an application can reach only the Google Drive files it created, or files the user explicitly opened or shared with it, for example through a Google file picker. FILOVA Backup has no file picker and never asks for files to be shared with it: it uses only the backup folder it created and the files in that folder. It cannot see the rest of Google Drive.
  • The Google Drive storage total and usage of the account.

It does not access email, contacts, calendar, photos or any other Google service.

How the data is used

  • To create the backup folder, and to upload, list, download and delete the backup files in it.
  • To warn the owner before the Google Drive storage runs out.

Google user data is used for nothing else: not for advertising, not for analytics and not to train artificial intelligence or machine learning models.

How the data is stored

  • Backup contents, including file names and folder structure, are encrypted with restic on the owner's computer before they are uploaded. The backup password is not uploaded to Google Drive.
  • The backup folder also holds restic's repository files. Its key files contain the repository key encrypted with the backup password, together with technical details in plain text: when the key was created, the user and computer name that created it, and the key-derivation settings. The stored files are named by content hashes, and their names, number, sizes and dates are visible to Google Drive.
  • The Google sign-in token is stored only on the owner's computer, in an encrypted configuration file.
  • The application has no server. Data moves only between the owner's computer and the owner's Google Drive.

Sharing

Google user data is not shared, sold or transferred to anyone.

Retention and deletion

Backups are kept in the owner's Google Drive until the owner's retention rules or the owner remove them. Deleting the backup folder in Google Drive removes them. Access can be withdrawn at any time under Google Account › Third-party apps & services.

Google API Services User Data Policy

FILOVA Backup's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes and contact

Changes to this policy are published on this page with a new effective date. Questions can be sent to the support email shown on the application's Google sign-in screen.
